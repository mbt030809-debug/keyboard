# MBT 키보드

갤럭시용 커스텀 안드로이드 키보드 (Kotlin, InputMethodService)

## 빌드
```
export ANDROID_HOME=/opt/android-sdk
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

## 설치 후 설정
1. 앱 실행 → "키보드 활성화" → MBT 키보드 ON
2. "키보드 선택" → MBT 키보드

## 진행 단계
- [x] 1. 프로젝트 세팅 + 빈 IME
- [x] 2. 한글 조합 엔진
- [x] 3. 두벌식·영어 자판
- [ ] 4. 단모음 자판
- [ ] 5. 숫자·기호·이모지
- [ ] 6. 테마·키 크기
- [ ] 7. 클립보드 히스토리
- [ ] 8. 서명 APK

## 한글 자판
- 단모음 (기본): 자음 + ㅏㅓㅗㅜㅡㅣㅐㅔ. 같은 키를 연달아 두 번(0.35초 내) 치거나 좌측하단 쉬프트를 누르면 ㄱ→ㄲ, ㅏ→ㅑ 등으로 변환
- 두벌식: 설정 화면에서 선택

## 갈라진 자판 (나눠쓰기)
- 폴드를 펼쳐 화면이 넓어지면(가장 짧은 변 600dp 이상) 자판 가운데를 비우고 왼손/오른손으로 나눔. 스페이스바도 둘로 갈라짐
- 접으면 자동으로 원래 자판으로 복귀. 설정 화면에서 끌 수 있음

## 입력 반응성
- 손가락마다 독립 처리(멀티터치): 앞 키를 떼기 전에 다음 키를 눌러도 입력이 빠지지 않음
- 쉬프트: 한 번 탭=켜기(글자 하나 치면 자동 해제), 빠르게 두 번=캡스락(⇪), 캡스락에서 한 번 더=해제. 누른 채 다른 손가락으로 입력하면 그 동안만 쉬프트

## 진동
- 설정 화면에서 켜기/끄기, 세기 1~10 조절 (조절할 때 체험 진동)
- 키 누를 때·꾹 누르기·스와이프에 적용

## 제스처
- 글자 키 꾹: 특수기호 후보 (밀어서 선택). 괄호·따옴표는 쌍("()" 등)이 기본이며 입력 후 커서가 안쪽에 놓임
- 글자 키 위 좌우 스와이프: 커서 이동. 쉬프트를 켠 상태에서 스와이프(또는 ◁▷)하면 이동하며 글자 선택
- 엔터 꾹: 상용문구 (앱 설정 화면에서 편집, 최대 4개)
- 스페이스바 좌우 스와이프: 한/영 전환
- 🎤(맨 위 줄 왼쪽): 음성인식. 누르면 듣기 시작, 다시 누르면 마무리 (첫 사용 시 마이크 권한 요청)
- 맞춤법(맨 위 줄): 선택한 글자(없으면 커서 앞 글자)를 온디바이스 규칙으로 교정. 되요→돼요, 몇일→며칠, 갈께→갈게, 할수있어→할 수 있어 등
- 😊(하단 왼쪽): 이모티콘(48개 카테고리)·이모지 패널

## 자판 구성 (위→아래)
- 상단 줄: 🎤 전체 복사 붙임 맞춤법 - ❤ @ ? !
- 숫자 줄: 1~0
- 글자 3줄 + 하단 줄
