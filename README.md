# MBT 키보드

갤럭시용 커스텀 안드로이드 키보드 (Kotlin, InputMethodService)

## 빌드
```
export ANDROID_HOME=/opt/android-sdk
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

## 설치 후 설정
1. 앱 실행 → "키보드 활성화" → MBT 키보드 ON
2. "키보드 선택" → MBT 키보드

## 진행 단계
- [x] 1. 프로젝트 세팅 + 빈 IME
- [x] 2. 한글 조합 엔진
- [x] 3. 두벌식·영어 자판
- [ ] 4. 단모음 자판
- [ ] 5. 숫자·기호·이모지
- [ ] 6. 테마·키 크기
- [ ] 7. 클립보드 히스토리
- [ ] 8. 서명 APK

## 한글 자판
- 단모음 (기본): 자음 + ㅏㅓㅗㅜㅡㅣㅐㅔ. 같은 키를 연달아 두 번(0.35초 내) 치면 ㄱ→ㄲ, ㅏ→ㅑ 등으로 변환
- 두벌식: 설정 화면에서 선택

## 제스처
- 글자 키 꾹: 특수기호 후보 (밀어서 선택)
- 글자 키 위 좌우 스와이프: 커서 이동
- 엔터 꾹: 상용문구 (앱 설정 화면에서 편집, 최대 4개)
- 스페이스바 좌우 스와이프: 한/영 전환

## 자판 구성 (위→아래)
- 편집·기호 줄: ◁ 전체 복사 붙임 - ❤ @ ? ! ▷
- 숫자 줄: 1~0
- 글자 3줄 + 하단 줄
