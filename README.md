# MBT 키보드

갤럭시용 커스텀 안드로이드 키보드 (Kotlin, InputMethodService)

## 빌드
```
export ANDROID_HOME=/opt/android-sdk
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

## 설치 후 설정
1. 앱 실행 → "키보드 활성화" → MBT 키보드 ON
2. "키보드 선택" → MBT 키보드

## 진행 단계
- [x] 1. 프로젝트 세팅 + 빈 IME
- [x] 2. 한글 조합 엔진
- [x] 3. 두벌식·영어 자판
- [ ] 4. 단모음 자판
- [ ] 5. 숫자·기호·이모지
- [ ] 6. 테마·키 크기
- [ ] 7. 클립보드 히스토리
- [ ] 8. 서명 APK

## 한글 자판
- 단모음 (기본): 자음 + ㅏㅓㅗㅜㅡㅣㅐㅔ. 같은 키를 연달아 두 번(0.35초 내) 치거나 쉬프트(ㅋㅌㅊㅍㅜㅡ 줄 맨 왼쪽)를 누르면 ㄱ→ㄲ, ㅏ→ㅑ 등으로 변환
- 두벌식: 설정 화면에서 선택

## 키보드 크기·위치 (설정 화면 → 크기 조정)
- 실제와 같은 미리보기 키보드를 보며 가로(50~100%)·세로(70~150%) 길이를 1%씩, 좌우·상하 위치를 2dp씩(좌우는 가로를 줄이면 이동, 상하는 바닥에서 0~200dp 띄우기) 조절. 누르고 있으면 반복(점점 빨라짐), 초기화 버튼
- 폴드를 접었을 때와 펼쳤을 때 각각 따로 저장
- 키 둘레 여백(위·아래·왼쪽·오른쪽 각각 0~40dp)과 키 사이 간격(0~16dp)을 1dp씩 조절
- 펼침 화면에서는 "갈라진 정도"(가운데 틈, 키보드 폭의 6~40%)도 조절

## 입력 타이밍 (설정 화면)
- 멈춤 기준(단모음): 0.3~3.0초 (기본 0.7초)
- 꾹 누르는 시간: 0.2~0.8초 (기본 0.35초)

## 갈라진 자판 (나눠쓰기)
- 폴드를 펼쳐 화면이 넓어지면(가장 짧은 변 600dp 이상) 자판 가운데를 비우고 왼손/오른손으로 나눔. 스페이스바도 둘로 갈라짐
- 한글은 왼쪽=자음, 오른쪽=모음으로 나뉨(단모음·두벌식 모두)
- 접으면 자동으로 원래 자판으로 복귀. 설정 화면에서 끌 수 있음

## 입력 반응성
- 손가락마다 독립 처리(멀티터치): 앞 키를 떼기 전에 다음 키를 눌러도 입력이 빠지지 않음
- 쉬프트: 한 번 탭=켜기(글자 하나 치면 자동 해제), 빠르게 두 번=캡스락(⇪), 캡스락에서 한 번 더=해제. 누른 채 다른 손가락으로 입력하면 그 동안만 쉬프트

## 진동
- 설정 화면에서 켜기/끄기, 세기 1~10 조절 (조절할 때 체험 진동)
- 키 누를 때·꾹 누르기·스와이프에 적용

- 단모음 입력 보정: `어`+`ㄷㄷ`(연타)는 받침(얻)이 아니라 다음 글자 `ㄸ`이 되어 "어떠"로 입력됨(ㅃ ㅉ도 동일). 모음으로 끝난 글자 뒤에서 0.7초 이상 멈췄다가 자음을 치면 받침이 아니라 다음 글자 초성이 됨

## 시작 언어
- 키보드를 띄우면 마지막으로 직접 고른 언어(스페이스바 스와이프)로 시작. 비밀번호·이메일·주소 입력칸에서만 임시로 영어, 다음 입력칸은 다시 원래 언어

## 제스처
- 글자 키 꾹: 특수기호 후보 (밀어서 선택). 괄호·따옴표는 쌍("()" 등)이 기본이며 입력 후 커서가 안쪽에 놓임
- 글자 키 위 좌우 스와이프: 커서 이동. 쉬프트를 켠 상태에서 스와이프(또는 ◁▷)하면 이동하며 글자 선택
- 엔터 꾹: 상용구 패널 (네모난 칸 3열, 행은 개수만큼 늘어나고 스크롤. 앱 설정 화면에서 한 줄에 하나씩 최대 100개 편집)
- 스페이스바 좌우 스와이프: 한/영 전환
- 🎤(스페이스바 바로 오른쪽): 음성인식. 누르면 듣기 시작, 다시 누르면 마무리 (첫 사용 시 마이크 권한 요청)
- 😊(하단 왼쪽): 이모티콘(48개 카테고리)·이모지 패널

## 자판 구성 (위→아래)
- 맨 윗줄(한 줄, 13칸 같은 폭): 전체 · 복사 · 붙임 · 1~0
  - 숫자 꾹 누르기: `1`→`!`, `2`→`@`
- 글자 3줄 + 하단 줄: `😊 , 스페이스 🎤 . ⏎`
- 꾹 누르기 기호 재배치: `.` → `… .com ·`, `/` → `/ | \`, `_` → `_ - —`, 물음표 `?`와 하트 `❤️`는 각각 비워진 글자 키에 하나씩. `★ ○ ※`는 삭제
- 글자 3줄 + 하단 줄
